# Company Logos Directory

This directory contains the company logos for the "Top Company" section on the homepage.

## Required Logo Files

The following logo files need to be placed in this directory:

1. `ana-intercontinental-logo.png` - ANA InterContinental
2. `prince-hotels-logo.png` - Prince Hotels
3. `sompo-care-logo.png` - SOMPO Care
4. `nissan-logo.png` - Nissan
5. `daikin-logo.png` - Daikin
6. `kandenko-logo.png` - Kandenko
7. `yoshinoya-logo.png` - Yoshinoya
8. `ana-logo.png` - ANA
9. `mitsubishi-heavy-industries-logo.png` - Mitsubishi Heavy Industries

## Logo Specifications

- **Format**: PNG with transparent background
- **Size**: Recommended 64x64 pixels (or similar square aspect ratio)
- **Quality**: High resolution for crisp display
- **Background**: Transparent (PNG with alpha channel)

## Where to Obtain Logos

### Legal Sources for Company Logos:

1. **Official Company Websites**

   - Visit each company's official website
   - Look for "Media Kit", "Press Kit", or "Brand Assets" sections
   - Download official logos with proper licensing

2. **Logo Databases (Free/Paid)**

   - [CompaniesLogo.com](https://companieslogo.com/) - 12,000+ company logos
   - [CompanyLogoFinder.com](https://companylogofinder.com/) - Free logo library
   - [Tickericons.com](https://tickericons.com/) - S&P 500 company logos
   - [Logggos.club](https://www.logggos.club/) - 1,000+ company logos

3. **Stock Photo Sites**
   - Shutterstock
   - Getty Images
   - Adobe Stock

## Important Notes

- **Copyright Compliance**: Ensure you have proper rights to use these logos
- **Trademark Respect**: Use logos only for legitimate business purposes
- **Quality**: Use high-resolution images for best display quality
- **Consistency**: Maintain consistent sizing and styling across all logos

## Current Status

The HTML has been updated to reference these logo files. Once the actual logo files are placed in this directory, the company cards will display the official company logos instead of the current worker images.

## Fallback

If a logo file is missing, the browser will display a broken image icon. Make sure all 9 logo files are present for the best user experience.
